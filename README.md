# Mile Vaganan V — Portfolio

A colorful, responsive React portfolio built with Vite.

## Run locally
1. Install Node.js (18+ recommended).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Personalize before publishing
- Replace `your.email@example.com` in `src/main.jsx` with your real email.
- Update the GitHub and LinkedIn profile links in `src/main.jsx`.
- Add real project screenshots, repository links, and a more detailed SmartCycle project description when ready.
- Add your education, certifications, and resume link if you'd like those sections.

## Build for deployment
Run `npm run build`. Upload the generated `dist` folder to a static host such as Netlify or Vercel.
